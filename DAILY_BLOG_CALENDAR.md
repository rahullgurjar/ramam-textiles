## Technical Publishing Workflow for Each Daily Post

To publish the daily blog post:
1. **Author the post** with 5 structured headings, technical definitions, and rich quotes.
2. **Assign high-intent SEO tags** and target category (`Craft Heritage`, `Fabric Sourcing`, `Sustainable Fashion`, `Care & Maintenance`, etc.).
3. **Generate/optimize photographic cover** (1200px max width, converted to `.webp`).
4. **Append to `src/data/journal.ts`** at the top of the array.
5. **Rebuild sitemap and static HTML routes** via `npm run build` or `node scripts/generate-sitemap.js`.
